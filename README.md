# Suministros Clave

Catálogo web público de insumos industriales y equipo de protección personal.

## Catálogo

- Stretch film industrial
- Gabacha industrial
- Locker metálico
- Guante de carnaza
- Fleje de polipropileno

La página incluye búsqueda, filtros, fichas de producto, selección para cotización y acceso a WhatsApp con mensaje precargado.
